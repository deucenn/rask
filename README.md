# rask

`rask` is a fast, lightweight command-line to-do list manager written in Rust.

## Installation

Ensure you have [Rust and Cargo](https://www.rust-lang.org/tools/install) installed on your system.

Clone the repository and install the binary globally using Cargo:

```bash
git clone [https://github.com/your-username/rask.git](https://github.com/your-username/rask.git)
cd rask
cargo install --path .
```
